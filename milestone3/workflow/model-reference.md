# Model Reference — Milestone 3 Public Reproducibility Note

Current draft, evidence-gate, and confidence-verifier model: `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`, pinned at revision `a9904d24bcc1d289a1950fa9d2b978c47cf903b9` (BF16 safetensors). The weights are publicly retrievable from the pinned Hugging Face model revision and are not duplicated in this course repository.

The experimental Milestone 2 adapter remains available in the private deployment repository but is **not** the current workflow's draft model. Historical adapter-draft measurements are labeled as historical in the report and are not attributed to the current base-draft configuration.

This public note identifies the model artifact and version for grading review; complete serving flags, installer, adapter bundle and live configuration are maintained in the private source-of-record repository.
