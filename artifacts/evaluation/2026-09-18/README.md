# Milestone 1 Per-Prompt Evaluation Evidence

This directory preserves the completed 512-token evaluation outputs used by the Milestone 1 report and reproducibility notebook.

## Systems

- `base/`: untouched Muse Glimmer 30B
- `adapter-muse-only/`: canonical 2026-09-17 clean QLoRA adapter
- `adapter-2026-09-18/`: second all-Muse QLoRA sensitivity candidate
- `comparison/base-vs-adapter-muse-only.json`: fail-closed formal comparison

Each system directory contains:

- `evaluation.jsonl`: 191 ordinary held-out per-prompt outputs and row-level diagnostics
- `evaluation.summary.json`: aggregate ordinary diagnostics
- `abstention.jsonl`: one quarantined unanswerable safety output
- `abstention.summary.json`: aggregate safety diagnostic

The expected answers were generated by the same local Muse family used for candidate creation. Therefore, these lexical, numeric, citation, truncation, and one-record abstention values are engineering diagnostics—not human-adjudicated factual accuracy. The 30-record student-authored control set is included separately, excluded from training, and reserved for human factual scoring.

The notebook verifies the files against `artifacts/milestone1/2026-09-22/evaluation_snapshot.json`, recomputes every displayed aggregate from the JSONL rows, and checks the formal comparison. Training and inference are not rerun by the notebook.
